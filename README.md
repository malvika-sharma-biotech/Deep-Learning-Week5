# Deep-Learning-Week5
Handwritten Digit Recognition using Python , TensorFlow and Deep Learning
Handwritten Digit Recognition Using Deep Learning
Project Overview

This project uses a deep learning neural network to recognize handwritten digits from 0 to 9 using the MNIST dataset.

Technologies Used
Python
TensorFlow and Keras
NumPy
Matplotlib
Scikit-learn
Google Colab
Dataset

The MNIST dataset contains 60,000 training images and 10,000 testing images. Each image is a 28 × 28 grayscale image.

Model Architecture
Flatten layer
Dense layer with 128 neurons and ReLU activation
Dropout layer
Output layer with 10 units
Evaluation

The model is evaluated using test accuracy, loss, precision, recall, F1-score, and a confusion matrix.

How to Run
Open the notebook in Google Colab.
Run the code cells in order.
Train the model.
Evaluate the results.
